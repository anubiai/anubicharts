AnubiCharts benchmark 
Choose an engine and press a button. Run each engine at least 3 times and ignore the first run (JIT and shader warm-up).
Keep the tab visible and in the foreground: browsers throttle hidden pages.
Method: the visible range is moved one step per animation frame (pan: 1 bar per frame; zoom: the range alternates between 0.5x and 2x of the visible bars). For each frame we record (a) the time spent in the script calling the chart API (this is NOT the render cost: both engines draw later, in the next animation frame) and (b) the interval between consecutive animation frames, which is the number that matters. The interval is capped by your display refresh rate (16.7 ms at 60 Hz), so an engine that keeps up shows the display period; a slower one shows larger values. GPU time is not measured directly. Lightweight Charts is loaded unmodified from a CDN. Please report your GPU, browser, OS, screen size and the numbers.
